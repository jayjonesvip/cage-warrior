# Icon asset overrides

Cage Grind keeps its current symbols as automatic fallbacks. To replace any
one of them, add a transparent PNG to this folder with the exact filename shown
below. For example, `heavy-bag-rounds.png` replaces the boxing-glove symbol on
the Heavy Bag Rounds action.

If the PNG loads, it replaces the fallback everywhere that icon is used. If it
is missing or cannot load, the original symbol remains visible. Square,
transparent artwork at 256×256 or 512×512 is recommended. After adding a new
file, use a hard refresh if the browser previously cached the missing image.
