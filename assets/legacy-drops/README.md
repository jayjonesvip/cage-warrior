# Legacy drop artwork

These files belonged to retired Cage Grind gear drops. They are intentionally
kept outside `assets/icons/` so they cannot be mistaken for active catalog
artwork, while remaining available for future systems or redesigns.

The active drop catalog is defined in `js/definitions.js`. Moving artwork into
this archive does not make an item available as a perk or drop.
